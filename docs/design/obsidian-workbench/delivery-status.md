## 能力边界

- LLM 通过明确复制材料到外部 Codex / Claude / 其他工具、将回答粘贴回来的方式使用。应用内供应商 API、自动生成/回传、流式响应尚未实现。
- 阅读器显示只读 Markdown 文本；尚未实现富文本渲染、PDF 内嵌预览、OCR。
- 真实附件支持在文件夹中定位；演示附件只有虚构文件信息，不创建文件。
- 方案说明已给出实际源码路径；三个布局共用状态与文件服务。
