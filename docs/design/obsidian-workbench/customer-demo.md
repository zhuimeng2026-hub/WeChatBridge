# 客户演示流程

1. 在 Windows 主程序中进入「知识工作台」，首先载入明确标为虚构的演示资料。
2. 先演示方案 3「阅读优先」：阅读原文，选取片段，在底部处理区准备请求、查看来源和结果保存路径。
3. 切换方案 2「案件工作区」：保留材料与草稿，展示案件维度、多材料勾选及双栏对照。
4. 切换方案 1「资料工作台」：展示目录搜索、原文/附件与右侧连续处理。
5. 经客户同意后连接其本地 Obsidian 库，展示文件发现、阅读和选择材料。不要在公开演示中使用真实私人材料。
6. 复制/转发明确选定的资料与指令给 AI Agent，将真实回答粘贴到草稿，核对引用后保存为新 Markdown，展示最终路径。

比较维度：阅读舒适度、案件对照效率、多文件整理效率、屏幕空间、处理范围清晰度。客户选择布局不会改变数据格式或迁移知识库。

当前是本地原生客户端实现；可安装包、CI 通过与视觉验收状态以 `delivery-status.md` 为准。
